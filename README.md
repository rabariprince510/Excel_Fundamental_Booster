# 📊 Fundamental Booster – Excel Project

## 📌 Project Overview

**Fundamental Booster** is a Microsoft Excel practice project designed to demonstrate essential spreadsheet skills, formula usage, data analysis, and data management. The workbook contains student grades, sales transactions, and employee records to practice Excel functions on real-world-style datasets.

The project focuses on using formulas to automate calculations, analyze information, retrieve records, and generate meaningful results.

## 🎯 Project Objectives

- Understand and apply fundamental Excel formulas.
- Perform calculations using logical and mathematical functions.
- Analyze data using conditional formulas.
- Extract and manipulate text using text functions.
- Work with dates and calculate employee tenure.
- Retrieve information using lookup and reference functions.
- Improve spreadsheet organization and data-handling skills.

## 📂 Project Structure

The workbook contains four worksheets:

| Worksheet | Description |
|---|---|
| Project Instructions | Project overview and list of Excel topics |
| Students Grade | Student details, marks, averages, and grades |
| Sales Data | Sales transactions, discount calculations, and final amounts |
| Employee Data | Employee details, salaries, joining dates, and tenure |

## 🛠️ Tools and Technologies

- Excel formulas and functions
- Spreadsheet data organization

## 📚 Excel Functions Used

### 1. Logical Functions

- `IF()` – Returns a result based on a condition.
- Nested `IF()` – Assigns grades based on student performance.
- `AND()` – Checks whether multiple conditions are true.
- `OR()` – Checks whether at least one condition is true.

### 2. Statistical and Conditional Functions

- `AVERAGE()` – Calculates the average of numerical values.
- `COUNTIFS()` – Counts records that meet multiple conditions.
- `SUMIFS()` – Adds values based on specified conditions.
- `AVERAGEIFS()` – Calculates averages based on specified conditions.

### 3. Lookup and Reference Functions

- `VLOOKUP()` – Searches for information in a table.
- `XLOOKUP()` – Retrieves matching information from a range.
- `XMATCH()` – Returns the relative position of a matching item.
- `INDEX()` – Returns a value from a specified position.
- `MATCH()` – Finds the position of a matching value.
- `INDIRECT()` – Creates a reference from text.
- `OFFSET()` – Returns a reference shifted from a starting cell.

### 4. Text Functions

- `LEFT()` – Extracts characters from the beginning of text.
- `FIND()` – Finds the position of specific text.
- `UPPER()` – Converts text to uppercase.
- `LOWER()` – Converts text to lowercase.

### 5. Date and Time Functions

- `DATEDIF()` – Calculates the difference between two dates.
- `TODAY()` – Returns the current date.

### 6. Mathematical Functions

- `ROUND()` – Rounds a number to a specified number of digits.
- `CEILING()` – Rounds a number up to a specified multiple.
- `FLOOR()` – Rounds a number down to a specified multiple.

### 7. Dynamic Array Functions

- `FILTER()` – Returns records that meet specified criteria.

## 📈 Worksheet Details

### Students Grade

This worksheet contains student IDs, names, subject marks, enrollment dates, average scores, and grades.

**Key operations:**
- Calculate average marks.
- Assign grades using nested `IF()` formulas.
- Check student performance using `IF()` with `AND()`.
- Extract first names using `LEFT()` and `FIND()`.
- Convert names to uppercase and lowercase.
- Summarize student performance using conditional functions.
- Filter students whose average score is above 80.

### Sales Data

This worksheet contains sales IDs, products, regions, salespeople, sales amounts, transaction dates, discount eligibility, discounts, and final amounts.

**Key operations:**
- Determine discount eligibility using logical functions.
- Calculate discounts and final transaction amounts.
- Summarize sales by region or product.
- Retrieve sales information using lookup functions.
- Explore dynamic references using `INDIRECT()` and `OFFSET()`.

### Employee Data

This worksheet contains employee IDs, names, departments, salaries, joining dates, and service-duration calculations.

**Key operations:**
- Calculate completed years of service.
- Calculate days since joining.
- Round salaries to the nearest hundred.
- Round salaries up or down to a multiple of 100.
- Retrieve employee information using lookup functions.

## 🚀 How to Use the Project

1. Download or clone this repository.
2. Open `1. Fundamental_Booster.xlsx` in Microsoft Excel.
3. Start with the **Project Instructions** worksheet.
4. Explore the Students Grade, Sales Data, and Employee Data worksheets.
5. Select formula cells to view the formulas in Excel's formula bar.
6. Change sample data to observe how the calculated results change.

## 💻 Requirements

- Microsoft Excel or a compatible spreadsheet application.
- A modern Excel version is recommended for functions such as `XLOOKUP()`, `XMATCH()`, and `FILTER()`.

**Note:** Some advanced formulas may not work in older Excel versions or other spreadsheet applications.
